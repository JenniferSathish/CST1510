# Week 2 — Decisions and Loops

**Box we build this week:** `PROCESS` — see `../system_diagram.md`

---

## By the end of this week you can

1. Compare values and combine conditions with `and`, `or` and `not`
2. Write a program that takes a different path depending on a condition
3. Explain why indentation is not just style in Python
4. Write a loop that repeats while a condition holds, and stop it safely
5. Write a loop that repeats a known number of times
6. Get the index and the value together while looping, with `enumerate()`
7. Choose between `while` and `for` for a given problem
